def is_prime(n):
    if n < 2: return False
    if n % 2 == 0: return n == 2
    i = 3
    while i*i <= n:
        if n % i == 0: return False
        i += 2
    return True

Quickstart

Serve in one command

Quantized builds are auto-detected — no quantization flag needed. Then call the OpenAI-compatible API.

sglang · launch server
# env: SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1  (for the full 1M context)
python3 -m sglang.launch_server \
  --model-path Blockway/Agens-Pilot-FP8 \
  --served-model-name "Agens Pilot" \
  --tp-size 4  --context-length 1048576 \
  --tool-call-parser qwen3_coder  --reasoning-parser qwen3 \
  --trust-remote-code  --port 8000
